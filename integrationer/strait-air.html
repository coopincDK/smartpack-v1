Hvad synkroniseres automatisk?

Fra ordren

  • Modtageradresse og kontaktoplysninger
  • Valgt leveringsmetode fra checkout
  • Pakkeshop-ID hvor det er relevant
  • Leveringsinstruktion og kundekommentar

På labelen

  • Reference fra ordren
  • Vægt og mål på kolliet
  • Valgt service og tilvalg
  • Afsenderoplysninger fra lokationen

Tilbage til webshoppen

  • Trackingnummer og tracking-URL
  • Fragtfirmaets navn
  • Alle kolli ved flere pakker
  • Fulfillment på ordren

Sådan hentes metoderne via WallBee

Strait Air-integrationen er bygget på WallBee-platformen, og metoderne kommer derfra.

# Fra aftale til leveringsmetode
jeres aftale      -> transportprodukter
WallBees API    -> henter produkterne
transportprodukt-ID -> påkrævet på metoden

Mangler transportprodukt-ID, fejler labeloprettelsen. Det er det første sted at kigge, hvis en booking ikke går igennem.

⚠️Fordi metoderne er dynamiske, kan vi ikke vise en fast liste her. Vi gennemgår jeres produkter ved opstart.

Spørgsmål og svar

Hvilke leveringsmetoder får vi?

▼

Dem jeres aftale dækker. Metoderne hentes dynamisk fra WallBees API ud fra jeres transportprodukter i stedet for fra en fast liste.

Hvorfor fejler vores labeloprettelse?

▼

Det hyppigste er, at transportprodukt-ID ikke er konfigureret. Det sættes enten på leveringsmetoden eller som parameter, og uden det kan labelen ikke oprettes.

Kan vi afregne told og moms på forsendelsen?

▼

Ja. DDP kan sættes som tilvalg, så told og moms afregnes ved afsendelse i stedet for hos modtageren.

Understøtter I farligt gods og tøris?

▼

Ja, begge er tilvalg på metoden. Det er relevant for blandt andet kemi, kosmetik og kølevarer.

Kan vi vælge CO2-neutral forsendelse?

▼

Ja, hvis jeres aftale dækker det. CO2-neutral er et tilvalg på leveringsmetoden.

Hvad er WallBee?

▼

Den platform, Strait Air-integrationen er bygget på. Det er derfor metoderne hentes dynamisk, og opsætningen ligner WallBee-integrationens.
